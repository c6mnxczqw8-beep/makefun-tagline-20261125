# One Line, One Week: the make.fun Tagline — entry

A program/v1 entry for the make.fun "The make.fun Tagline"
bounty. `main.py` writes one tagline to `/output/entry.txt`
(or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is
set).

The tagline:

> Post a problem. Wake up to a leaderboard.

The whole marketplace in seven words: the posting, the
sleeping, the results. See `CANDIDATES.md` for the full draft
list this winner was picked from.
